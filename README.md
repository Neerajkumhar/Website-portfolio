# VISUARK Website Special Portfolio

A creative digital portfolio website for VISUARK, a brand designer crafting minimal and elegant websites, visual identities, videos, and digital experiences.

## Description

This is a responsive portfolio website built with React, Vite, and CSS. The design features a warm cream, terracotta, olive green, and bronze color palette with the Radley serif font for headings and Carlito for body text.

## Features

- Smooth page transitions with `scroll-behavior: smooth`
- Responsive design that scales from 320px to 1920px
- Hand-drawn decorative elements with bronze accents
- Section-based layout: Hero, About, Design Focuses, Project Gallery, Testimonials, Contact
- External project links with target `_blank`
- Functional contact links (phone, email)
- Accessibility features (skip link, aria labels, focus-visible states)
- `prefers-reduced-motion` support

## Technologies

- React 18
- Vite 5
- CSS custom properties with `clamp()` for fluid typography
- Fonts: Radley (serif) and Carlito (sans-serif)
